# 🔑 Breath Care - 로그인 및 회원가입 인증 규칙 문서 (LOGIN_RULES)

본 문서는 **Breath Care** 애플리케이션의 인증 체계, 로그인/회원가입 규칙, 유효성 검사 기준 및 예외 처리 정책을 정리한 문서입니다.

---

## 1. 📌 회원가입 규칙 (Sign Up Rules)

| 항목 | 입력 규칙 | 비고 및 검증 예외 메세지 |
| :--- | :--- | :--- |
| **이름 (닉네임)** | 필수 입력 (공백 제외 1자 이상) | `'이름(닉네임)을 입력해 주세요.'` |
| **아이디 (이메일)** | 표준 이메일 형식 (`@` 및 도메인 포함) | `'유효한 이메일 형식을 입력해 주세요.'` |
| **비밀번호** | **최소 8자 이상 ~ 최대 64자 이하** | `'비밀번호는 8자 이상 64자 이하로 입력해 주세요.'` |
| **비밀번호 확인** | 비밀번호 필드와 100% 일치 | `'비밀번호가 일치하지 않습니다.'` |

> 💡 **가입 프로세스**: 회원가입이 완료되면 즉시 로그인 토큰이 생성되고 자동 로그인 처리되어 홈 화면으로 바로 진입합니다.

---

## 2. 🔐 로그인 규칙 및 컷오프 처리 (Login & Security Cut-off Rules)

| 입력 항목 | 입력 규칙 | 예외 처리 및 출력 오류 메세지 |
| :--- | :--- | :--- |
| **아이디 (이메일)** | 미입력 시 | `'아이디(이메일)를 입력해 주세요.'` 스낵바 알림 |
| **비밀번호** | 미입력 시 | `'비밀번호를 입력해 주세요.'` 스낵바 알림 |
| **이메일 형식 미충족 / 미가입 계정 / 비밀번호 불일치** | `@` 미포함, 가입되지 않은 이메일, 틀린 비밀번호 등 잘못된 모든 시도 | **`"존재하지 않는 계정이거나 비밀번호가 일치하지 않습니다."`**<br>단일 정밀 차단 메세지 출력 |

---

## 3. 🛠️ 소셜 로그인 및 이메일/비밀번호 찾기 안내

1. **소셜 로그인 (`Google로 계속하기`)**
   * **상태**: UI 알약 버튼 연동 완료 (`assets/images/ic_google.png` 에셋 등록됨).
   * **동작**: 추후 소셜 SDK 연동 시 백엔드 `/api/auth/social` API와 연동됩니다.

2. **`이메일/비밀번호 찾기` 링크**
   * **상태**: 화면 디자인에 따라 중앙 밑줄 텍스트로 노출됩니다.
   * **동작**: 클릭 시 알림 문구나 토스트 메시지를 출력하지 않습니다 (Silent text link).
